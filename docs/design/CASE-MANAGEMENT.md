# Case Management — AT-18 / 09.3
2026-11-24 | Proposed UX for product review; no implementation or deployment.
Sources: [Master](../MASTER-BLUEPRINT.md), [ADR-006](../adr/ADR-006-service-catalog-case-workflows.md), ADR-002/003/004/005/007/008/009, [AT-03](../specifications/AT-03-decisions.md), [AT-08](../specifications/case-deadlines.md), AT-04 proposal, SAAS-APPLICATION-SHELL.md, DEALER-DASHBOARD.md. Domain specifications override UX; exact state machine, SLAs, task and API contracts remain open in AT-07.

## Routes and layout
Proposed /empresa/expedientes, ?scope=mine, ?view=kanban, ?scope=archived, /nuevo, /[id], /calendario. Shell 256/72px sidebar, 64px topbar, 24px content padding; Inter, Lucide, existing light/dark tokens. Header Expedientes, count, Nuevo expediente if permitted; search, filter drawer, saved views (proposal), table/board toggle. Mobile cards, horizontal board columns with accessible list alternative, sticky primary action if authorized. No sensitive data in URLs or saved filters; shareable filters limited to non-sensitive authorized identifiers.

## Table
Columns: reference, service, customer minimized name, masked vehicle identifier, branch, responsible employee, workflow status, priority, document progress, next applicable deadline/type, updated timestamp, actions. Default sort urgent then next verified deadline then updated, stable tie-breaker; provisional dates labeled separately. Configurable columns and server pagination, 25/50/100 proposed; select only authorized rows, clear selection on scope/filter changes. Row opens detail; keyboard-accessible actions menu. Bulk assignment/export only explicit permission and per-row validation; preview scope/count, partial failure report, audit; no bulk regulated filing, payment or arbitrary status changes. Export finance/personal/bulk permissions distinct per AT-03 decision 27; short-lived protected file.

## Filters
Search reference, authorized customer name, VIN/plate if permitted; no cross-tenant autocomplete. Filters service/version, canonical status, branch, assignee/unassigned, priority, legal/internal deadline window, overdue, provisional/legal review, missing documents, receipt exceptions, created/updated/completed range, archived, payment status only if permitted. AND across categories, OR within category; clear all, active chips, result count, empty vs unavailable. Scope Mis expedientes uses authorized assignment, not a new permission. Dashboard drilldown preserves predicate and date/snapshot semantics. Saved views private by default, no personal search text persisted; sharing pending authorization design.

## Kanban
Illustrative display groups Borrador, Documentación, En revisión, En trámite, Finalizado; separate canceled/archive view. These are not canonical enums or a mandatory linear workflow. Map versioned service states to display groups; unmapped states shown explicitly, flags (legal review, payment, receipt exception) orthogonal. Card reference, service, masked vehicle, assignee, deadline, document progress and flags. Counts reflect authorized filter; paginated columns. Drag/drop optional only for server-advertised transitions, accessible menu equivalent, confirm consequences and required reason/evidence, reject stale version and reload. No optimistic success, no bypass of checklist, payment, professional mandate or legal holds; moving card never itself submits to authority. Read-only roles cannot move.

## Create wizard
1 Centro + Servicio: active authorized branch (explicit even in aggregate), published catalog/version, eligibility and requirements. 2 Cliente y representación: select/create tenant-local customer, roles applicant/owner/payer/representative distinct, mandate verification; no global lookup or automatic merge/claim. 3 Vehículo: select/create authorized record, VIN/plate validation according to service, unknown allowed only where catalog permits. 4 Datos y documentos: dynamic versioned fields, required/conditional checklist, secure upload, validation and missing-item explanation; drafts permitted only under approved domain rules. 5 Presupuesto y pago: versioned retail price, statutory fees/taxes separately, dealer-funded discount only authorized, payer and deferred/prepaid options, server credit check; pending collection not settled. 6 Revisar y crear: summary, applicable terms/mandates, explicit confirmation; idempotent submit, prevent duplicate retries, distinguish saved draft, created case, payment pending and actual official filing. Draft recovery and unsaved changes warning; no unverified statutory deadline or guaranteed completion. No mandatory login for public guest flow; this wizard is dealership-only.

## Detail workspace
Header reference, service/version, branch, status, priority, assignee, next deadline, allowed primary action and menu. Tabs Resumen, Documentos, Tareas, Plazos, Comunicaciones, Finanzas (permission), Historial. Summary customer/vehicle/representation, checklist, next action, partner assignment and blockers. Desktop main 8 columns + 4-column contextual panel; mobile stacked. Each tab deep-link reauthorizes. Edit facts with reason where required, concurrency conflict handling and audit; no silent catalog migration. Distinguish official submission, receipt verification and completion; closure only approved workflow conditions; archive does not delete; post-closure review separate from original completion, corrections need scoped approval and legal authority. Cancellation/reopen rules pending AT-07.

## Documents
Required/conditional checklist by service version; received vs validated vs missing vs rejected clearly distinct. Show version, type, upload time, reviewer, reason, safe preview/download if authorized. Upload progress, retry, quarantine/validation pending, reject unsafe files; exact scan/size/retention pending AT-09. OCR suggestions never verified facts automatically. Request supplement via authorized communication, no public links. Official receipt CSV validation pending/failed/verified, manual evidence acceptance distinct, mismatch/duplicate/revocation flags; no cross-tenant disclosure. Never clear legal deadline solely on OCR or unverified receipt. Short-lived scoped object access, RLS metadata, audit access, no public storage or private thumbnails in demo.

## Deadlines and tasks
Separate legal/internal deadlines, verified/provisional, authority, rule/calendar version and source provenance. Calendar list/week/month with accessible agenda, filters and explicit timezone. No UI calculation of legal dates; applicable authority calendar not branch address. Legal dates read-only for tenant roles; report incorrect facts with evidence, central review. Internal edit OWNER/ADMIN, scoped MANAGER, responsible EMPLOYEE subject to access; audit old/new/time/actor. Legal review preserves unrelated work, blocks only dependent actions; resolution does not auto-execute. Alerts 7/3/1 days, due date, daily overdue; no backfill, deduplicate, stop when no longer applicable. Task list owner, due, status, dependencies, completion evidence where required; notification read != completion. Priority separate from deadline, exact priority taxonomy pending. Receipt revocation and post-closure review surfaced independently.

## Assignment and branch transfer
Assignee picker active eligible members in case branch only; display workload only authorized, no automatic allocation assumed. OWNER/ADMIN and scoped MANAGER with applicable permission assign; employee self-assignment only if explicitly authorized (pending AT-07). VIEWER read-only. Assignment change reason, server validation, audit and notification. Deactivation immediately revokes access; unfinished cases to manager/admin/owner or reassignment queue, daily reminders and escalation after 72h per AT-03. Branch transfer OWNER/ADMIN within same tenant active branches; MANAGER permitted between own branches; EMPLOYEE requests approval. Check status/target restrictions, update assignment, preserve origin and history; no change legal entity or credit. Cross-tenant transfer not ordinary UI action. Regulated filing separately checks professional entitlement and client mandate; Ficha Reducida procured by AutoTramita from qualified engineer, no direct customer procurement requirement.

## Timeline and communications
Chronological business events with actor, timestamp, action, old/new values where allowed, reason, evidence link, filters and pagination. Separate immutable audit from user-visible timeline and editable notes; internal notes never automatically customer-visible. Customer/partner messages explicit recipient and visibility, secure attachments, delivery state distinct from read; no passwords or sensitive previews. Audit access, status, assignment, deadline, documents, financial actions per AT-03; no raw secrets. 
## Security and states
Every list/count/card/detail/action/export server scoped to active tenant/branch/membership and entitlement, RLS and object authorization; context switch clears stale data. Candidate/suspended/closed tenant restrictions per AT-03; credit-only block preserves prepaid per ADR-007. Loading, empty, filtered empty, partial failure, retry, stale conflict, permission revoked, expired session, offline no private cache by default. WCAG 2.2 AA, keyboard, visible focus, status text not color only, 320px/200% zoom, light/dark/system. Generated clients ADR-004; no API or database changes.
