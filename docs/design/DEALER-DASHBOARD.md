# Dealer Dashboard — AT-18 / 09.2
2026-11-24 | Proposed UX for review | No implementation or deployment.
Sources: SAAS-APPLICATION-SHELL.md, BRAND-IDENTITY.md, ../adr/ADR-002-multi-tenancy-rls.md, ADR-003/006/007/009, ../specifications/AT-03-decisions.md, ../specifications/case-deadlines.md, AT-04/07/08/12/13/14/16/19. Domain rules override this proposal. Route /empresa (proposed).

## Layout
Use existing shell and theme tokens, Inter/Lucide. Desktop 12-column grid, 24px gap, header Inicio + Nuevo expediente, context and last successful refresh. Four KPI cards, quick actions, urgent work queue, credit and finance panel, activity trend and service breakdown, recent cases and activity. Urgent work before analytics on mobile; 2-column KPI tablet, 1–2 mobile depending on width, tables become cards or accessible internal scroll. No private data in static mockups. All amounts EUR es-ES, explicit timezone and as-of timestamp.

## Filters and scope
Empresa and Centro inherited from server-authorized shell; Todos los centros only authorized aggregate scope. Personal queue toggle Mis tareas / Equipo only when permitted. Date range 7/30/90 days or custom proposed; affects period metrics/charts, not current active stock, credit, open tasks or deadline snapshot. Label each card snapshot or period. Default 30 days; date intervals inclusive local dates converted to half-open timestamps in approved reporting timezone. Reset filters on tenant change, cancel old requests and clear previous data. No cross-tenant aggregation. Distinguish company-wide credit from branch-filtered operations; hide company totals without company finance permission.

## KPI definitions (proposed, canonical mappings pending AT-07/19)
Activos: distinct authorized nonterminal cases as of snapshot, excluding drafts unless explicitly labeled. Finalizados: distinct cases with completion event in selected period, exclude canceled; define reopened handling with AT-07/19 before implementation. Pendientes de documentación: distinct active cases with outstanding required document request, not number of files. Plazos vencidos: distinct active cases with applicable unresolved overdue deadline, separate statutory/internal and provisional review. Drilldown preserves scope, date and predicate; overlapping KPIs not additive. Optional new cases count based on creation event. Zero only on successful empty response; unavailable shown dash. Comparison previous equal-length period only if comparable, no divide by zero; no invented trends.

## Work queue and case table
Urgent queue: overdue verified statutory, upcoming statutory, internal deadlines, legal review and document/receipt exceptions, with explicit labels; exact prioritization per AT-08, not a new legal rule. Show case ref, service, task, responsible person if permitted, deadline type/date, priority, action. Distinguish provisional/unverified dates, legal review, receipt verification failures/revocations and post-closure review; never silently clear warnings from OCR or pending verification. Alerts 7/3/1 days, due day and daily overdue per approved deadline spec; no new calendar computation in UI. Legal review blocks only dependent actions per server. Tasks separate from notifications; read does not complete task. Sort by authorized urgency/deadline, pagination and empty states; completion only via approved task transition, not a dashboard checkbox. Recent cases columns ref, service, vehicle masked identifier as permitted, customer minimized display, branch, assignee, status, next deadline, last update; row opens authorized case. No raw identity numbers or document thumbnails. Status labels mapped from canonical workflow, no invented enums. View all preserves filter and permission. Activity shows authorized event summary/time/actor if allowed; not a replacement for audit log.

## Finance and credit
ADR-007: one tenant credit facility, centrally set by AutoTramita, not per branch. Display L approved limit, R outstanding reservations, U utilized exposure, A available as authoritative ledger values; illustrative A=max(0,L-R-U) only if R/U disjoint and no other restrictions; never subtract unpaid receivables again when included in U. Show contractual headroom separately from usable credit if blocked; no client-side authorization or recalculation of authoritative values. Example L 20,000; R 2,000; U 8,000; A 10,000. Show prepaid-only, active, credit suspended, unavailable states. Credit-only suspension after three applicable business days beyond due date per ADR-007, not tenant suspension; prepaid remains available, existing cases not auto-canceled. Reactivation only after confirmed settlement of all overdue obligations subject to other restrictions. No countdown without approved applicable calendar. Show outstanding receivables, overdue subset, pending collection, confirmed payments separately; pending collection may overlap receivables, never add as independent debt. No pending card/SEPA marked paid. Invoice due dates immutable under changed terms. Finance period flows separate from balance snapshot; no revenue/margin claims until accounting definitions approved. Unified public price, dealer-funded discount, statutory fees separate; no change limit action for dealership. Links Ver crédito / Ver facturas / Pagar factura only if authorized and available; no payment initiated from preview. Provider, funds flow, grace handling, calendar and exact ledger formulas pending domain approval.

## Charts
Trend: created vs completed cases by day/week/month based on range; separate event counts, not active stock. Service mix: created cases by versioned service category, count and percentage denominator explicit, unknown category retained; no double-counting multi-service cases until attribution rule approved. Accessible data table and text summary, keyboard-accessible legend, no color-only distinctions. Finance chart optional only authorized, confirmed payment flows by settlement date, refunds separately, not profit. No interpolation of missing values. Empty, partial and unavailable states; no misleading zero. 
## Quick actions and roles
Nuevo expediente, Nuevo cliente, Nuevo vehículo, Nuevo presupuesto, Subir documento (requires authorized target case). Only permitted actions; specific branch required when applicable, no mutation in aggregate scope without explicit branch selection. Draft/verification tenant no production actions; suspended tenant restrictions per AT-03; credit block only deferred credit actions. OWNER/ADMIN all branches subject to permissions; MANAGER assigned branches; EMPLOYEE assigned branches and operational permissions; VIEWER read-only. Finance, discount, deferred payment, exports separate permissions. No dashboard privilege escalation. No real actions in mockup.

## Loading and accessibility
Independent panel loading/error/retry, timestamp and stale warning, manual refresh, no polling cadence assumed; background refresh must not overwrite changed context. Partial failure does not imply zero or hide urgent warnings. Server authorization/RLS for every aggregate, count, drilldown and export; no private shared caches, no unauthorized counts. No new API contracts; generated clients per ADR-004. WCAG 2.2 AA, keyboard, focus, reduced motion, 320px width, 200% zoom, light/dark/system.
