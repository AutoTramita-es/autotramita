Sources: ../MASTER-BLUEPRINT.md; ADR-001/002/003/004/005/006/007/008/009; ../specifications/AT-03-decisions.md (27 confirmed decisions); BRAND-IDENTITY.md, ICON-SYSTEM.md, PUBLIC-AUTH-SUPPORT-LEGAL.md. Domain rules override this UX proposal.

## Shell geometry
Desktop >=1280: 256px sidebar, collapsible to 72px; 64px topbar; content padding 24px, fluid width, breadcrumb and page title/action row. Tablet 768–1279: compact rail or overlay drawer; mobile <768: 56px topbar, modal navigation drawer, 16px padding, optional bottom navigation for customer portal (Inicio, Expedientes, Avisos, Cuenta); no duplicate navigation landmarks. At 320px no page overflow; wide tables scroll within labeled region or use cards. Sticky header/sidebar independently scroll; keyboard focus never obscured. Inter, 44px navigation targets, 20px Lucide icons, 48px primary controls. Sidebar logo, workspace label, grouped links, help and collapse; topbar menu, context selector, scoped search, notifications, theme, profile. Breadcrumbs and page actions contextual. No dashboard metrics specified here.

## Context selection
Global User can have personal entitlement and several active memberships. Profile workspace switcher “Cambiar espacio de trabajo” lists only server-authorized contexts. Dealer topbar “Empresa” then “Centro”; show name and branch code; OWNER/ADMIN all current/future branches, MANAGER/EMPLOYEE/VIEWER assigned branches only. “Todos los centros” only if server explicitly authorizes aggregate read scope; mutations require valid specific branch when applicable. One legal entity per tenant, shared credit; branch switch not a credit switch. Single authorized option can be read-only. No production workspace for candidate OWNER or pending tenant; onboarding status view only. Suspended/closed contexts follow AT-03 restricted access policy; credit-only block preserves prepaid access.
Switch: check unsaved changes (save if allowed/discard/cancel); request server validation; show loading; cancel/ignore old requests, clear previous context queries/search/notifications/drafts from visible state, revoke old transfer links where supported, reset filters and selection; navigate safe landing; announce new context. On failure retain previous authorized context or lock if revoked; never display old data under new heading. Session-specific active tenant/branch, not shared global preference; multiple tabs must avoid stale context via server validation and explicit context/version checks. Deep links reauthorize resource, offer authorized context switch only after safe verification, otherwise generic denied/not found. No arbitrary tenant IDs trusted. RLS, storage, cache, workers and API authorization remain mandatory.

## Role UX
OWNER: all branches, reserved owner actions and admin membership management subject to verified transfer and last-owner safeguards. ADMIN: all branches, operational administration; cannot grant OWNER or ADMIN. MANAGER: assigned branches, delegated employee/viewer invitations only with explicit permission. EMPLOYEE: assigned branches, operational actions per permissions; transfer request subject to approval. VIEWER: read-only authorized scope. Separate discount/deferred payment permissions and employee limits; only AutoTramita sets credit limits/terms. Export permissions separate for finance/personal/bulk. No role self-elevation. Detailed matrix pending reconciliation of AT-03 and tenant-membership spec. Revocation immediate, no stale access; optional 2FA for dealership roles including OWNER/ADMIN; other role MFA pending AT-02. Support default technical diagnostics; business access time-limited approved OWNER/ADMIN or exceptional audited authorization; no invisible impersonation.

## Topbar and notifications
Search placeholder “Buscar expedientes, clientes, vehículos…” adapted to workspace; only authorized indexed results, no cross-tenant suggestions or sensitive query telemetry; exact search scope pending. Keyboard shortcut optional and documented; escape closes. Bell with authorized unread count (99+ cap), popover “Notificaciones”, filters “Todas / Sin leer”, mark read and “Ver todas”; each item time, type, concise non-sensitive summary, safe deep link. Examples: document supplement, case status, task/deadline, confirmed payment, credit restriction, invitation; actual events and channels AT-16. Global account security notices separated from workspace notices. Reauthorize on open; mark read not equivalent to task completion; no pending payment shown settled. Loading/empty/error/retry, no fake count, avoid sensitive push/email previews. Profile: Mi perfil, Seguridad, Sesiones, Cambiar espacio, Apariencia, Cerrar sesión; device sessions and revocation per AT-03. Locale es-ES, EUR, timezone explicit per domain; no hardcoded holiday calculations.

## Themes
Light: canvas #F5F7FA, surface #FFFFFF, text #082344, secondary #475569, border #CBD5E1, primary #005BCB, selected #EFF5FC. Dark: canvas #0B1728, surface #12243A, text #F1F5F9, secondary #B8C7DA, border #40536B, link #60A5FA, primary button #005BCB with white, selected #203C60. Semantic success/warning/error use text+icon, contrast verified before implementation; focus ring distinct from status. Theme options Claro/Oscuro/Sistema; system follows OS, explicit preference persists per user/device as approved, no sensitive data in preference storage. Avoid flash, honor reduced motion and forced colors. Logo variants appropriate to background. WCAG 2.2 AA target, 4.5:1 normal text, 3:1 relevant UI boundaries and large text; test actual combinations.

## Shell states
Initial session/context loading skeleton without private stale data; no authorized workspace -> onboarding/help; session expired -> login safe return; access revoked -> clear protected state and safe landing; 403/404 generic; offline -> read-only only if approved safe caching (default no private offline cache); retry on network error; maintenance banner; unsaved form navigation confirmation. No optimistic authorization or financial success. Screen reader landmarks, skip link, focus restoration for drawer/popovers, escape, keyboard navigation, live status, no color-only signals. Mobile drawer traps focus while modal and restores on close. Responsive tests 320/375/768/1024/1280/1440, zoom 200%, keyboard and screen reader. API via generated clients ADR-004, no new contracts here.
