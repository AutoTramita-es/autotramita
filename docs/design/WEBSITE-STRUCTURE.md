# AutoTramita.es — Public homepage UX v1.0
Date: 2026-11-24. Status: proposed for product-owner review; no implementation or deployment.
Parent: AT-18, [Brand identity](BRAND-IDENTITY.md), [Icon system](ICON-SYSTEM.md), [Patterns](BACKGROUND-PATTERNS.md), [Hero banners](HERO-BANNERS.md).

## Goals
Spanish-first public site for private vehicle owners, dealerships, importers and professional partners. Primary conversion: start an eligible published service without mandatory account registration. Secondary: qualified B2B contact and existing-user login. No claim of government affiliation, guaranteed timing or universal fully remote completion.

## Layout
Inter, navy #082344, blue #005BCB, ice #EFF5FC, white, slate #475569. Desktop max content 1280px, 32px gutters, 12-column grid, 24px gaps; 72px header; sections 80px vertical spacing. Tablet 24px gutters and 56px sections; mobile 16px gutters and 40px sections. H1 48/56 desktop, 32/40 mobile. Body 16/24. Buttons 48px high, radius 10px; cards radius 16px, subtle border and shadow. Light-first public site; dark variant follows brand tokens and tested contrast. No auto-rotating hero.

## Responsive and states
Desktop services 3 columns, process 5 columns; tablet services 2 and process 2–3; mobile services and process 1 column, no horizontal overflow at 320px. B2B section 2 columns desktop, stacked mobile. Keyboard-operable menu/FAQ, focus restoration, skip link, semantic landmarks, single H1, reduced motion. WCAG 2.2 AA target; test text and control contrast. Catalog loading uses skeleton with status; error shows retry and contact; empty shows “No hay servicios disponibles en este momento”. No fake fallback pricing. CTA disabled only with clear explanation; preserve entered non-sensitive data on recoverable errors.
